## 1. 概述

alg 是一套面向 ComUI 宿主的 C++ 算法库，提供几何/图像/点云原子算子、通用模块与业务编排能力。库整体为**六层单向依赖架构**（上层依赖下层，禁止反向）：

| 层 | 模块 | 职责 | 对外接口形态 |
|----|------|------|--------------|
| 业务层 | `src/BusinessAlg` | 流程编排、业务语义（区域占比、bump NG） | C API + ComUI 节点 |
| 通用 3D | `src/Point3DAlg` | SICK Ranger3 扫描读取、点云配准与量测 | C API + C++ 量测层 + ComUI 节点 |
| 通用 2D | `src/Image2DAlg` | 2D 图像读取/处理/测量、相机标定 | C API + C++ 标定类 + ComUI 节点 |
| 基础库 | `src/ShapelyAlg` | 几何/图像/点云原子算子（GEOS/OpenCV/PCL） | C++ 类接口 |
| 最底层 | `src/CommonAlg` | JSON/文件/日志通用能力 | C++ 函数/类接口 |
| 集成层 | `integration/comui` | ComUI 宿主接入协议（C ABI 适配 + 83 个 node.json） | 统一 C ABI |

**算法模块零 UI 痕迹**：ComUI 适配代码全部集中在 `integration/comui/`，编译产物仍是算法 DLL。

本文档按"接口使用者视角"组织：先看全局约定（第 2 章）与接口地图（第 3 章），再按模块逐接口给出**原理**（算法/数学/设计动机）与**使用说明**（签名、参数、返回、示例、注意）。

## 2. 全局约定（先读）

### 2.1 单位与精度

- **单位**：无全局强制，本项目惯例 **mm**；所有几何量（面积 mm²、距离 mm、偏差 mm）与输入坐标同单位。图像类算子单位为**像素**。
- **精度**：ShapelyAlg 内部统一 `double`，输入 `int/float` 自动向上转型，无精度损失。

### 2.2 错误处理

- **所有 C 接口返回 `int` 错误码**（`0` 成功、`<0` 失败），**不跨 DLL 边界抛异常**（C++ 异常在 C 边界统一捕获转码）。
- ShapelyAlg（C++ 库）全库不抛异常，失败表现为：空对象（`isEmpty()==true`）、数值 `0/-1`、布尔 `false`、指针 `nullptr`。
- ComUI 节点返回码：`0` 成功、`1` 输入缺失、`2` 输入无效、`3` 参数/内存问题、`4` 量测业务失败。

### 2.3 内存规则

- C API 的输出缓冲（`out_image->data`、测量结果数组）一律由库内 `malloc` 分配，调用方用对应 `Free*` 函数释放：
  - 图像缓冲 → `Image2DAlg_FreeImage`
  - 测量数组 → `Image2DAlg_FreeBlobs` / `FreeContours` / `FreeMatches` / `FreeCircles` / …（均 NULL 安全）
  - 点云缓冲 → `Point3DAlg_FreeBuffer`（ReadSickCloud 与 SICK 句柄族）/ `Point3DAlg_FreeCloud`（`PointCloud` 容器）
- ComUI 节点输出缓冲由节点 `malloc`，宿主用同 DLL 导出的 `algo_free(void*)` 释放；`error` 为 UTF-8 静态存储，宿主只读不释放。
- 输入容器仅作只读视图，算子不修改输入，生命周期归调用方。

### 2.4 线程性

- C API 算子无全局状态，可多线程并发调用（`Init/Cleanup` 为占位）。
- ShapelyAlg：GEOS 上下文线程局部，**多线程各建各的对象并行计算安全**；单个 `Geom`/`Stereo` 对象不可跨线程并发；`ImageProcessor`/`CloudProcessor` 为无状态静态方法，线程安全。

### 2.5 导出宏与 ABI

- 统一导出宏 `AlgExport.h`：编译 DLL 时定义 `<MODULE>_BUILD_DLL` → `dllexport`；使用方不定义 → `dllimport`。开关宏必须是 `<MODULE>_BUILD_DLL`，不能写成 `-DSHAPELYALG_EXPORT`（否则宏展开成 `1 class Geom`）。
- C 接口全部 `extern "C"` 包裹，防名字改编（dumpbin /exports 可核对）。

### 2.6 关键约定速记

| 约定 | 内容 |
|------|------|
| 图像坐标系 | 原点左上，x 右 y 下；行步长 = `width * channels`，无对齐填充 |
| 图像通道 | C API 输入 1(灰度)/3(BGR)/4(BGRA)；通用算子保持通道，天然单通道算子输出 1 通道；`ReadImage` 固定 BGRA |
| 点云布局 | SoA 交错 `[x0,y0,z0,x1,y1,z1,...]`；ComUI `AlgoCCloud` 同 |
| 变换矩阵 | 4×4 行主序 `float[16]`，`p_target = T·p_source`；文本格式 16 值逗号分隔 |
| OBB3d | `extents` 为半长，`rotation` 行主序（第 d 行 = 第 d 主轴方向） |
| 鸭子类型 | ShapelyAlg 工厂模板只要求元素含 `.x/.y`（3D 再加 `.z`）成员 |

## 3. 接口分层总览

本项目"接口"分三类，使用方式不同：

1. **C API（头文件导出函数）**：调用方直接链接 `.lib` 并 `#include` 头文件。包括 CommonAlg / Image2DAlg / Point3DAlg / BusinessAlg 的 `extern "C"` 函数。
2. **C++ 类接口**：ShapelyAlg 全库、Image2DAlg_Calib、Point3DAlg_SickReader 与 `tools/` 量测层。直接 `#include` C++ 头文件链接。
3. **ComUI 节点算子**：宿主按 `node.json` 声明动态加载 DLL，调用统一入口 `int f(const AlgoCInput*, AlgoCOutput*)`；参数按 `node.json` 声明顺序以 `AlgoCParam` 数组传入（宿主 marshal **不带参数名**）。

**接口数量概览**：

| 类别 | 数量 | 详见 |
|------|------|------|
| ShapelyAlg C++ 算子 | 200+（Geom 40+、Stereo 20+、ImageProcessor 90+、CloudProcessor 90+、IO 10+） | 第 5 章 |
| Image2DAlg C API | 95（api.h 导出函数，含基础层 5 与 Free* 17） | 第 6 章 |
| Image2DAlg 标定 C++ API | 12 | 6.5 节 |
| Point3DAlg C API | 42（api.h 28 + SickApi.h 9 + SickReader.h 5；其中点云计算族 22 个按 PCL_FOUND 守卫） | 7.1~7.3 节 |
| Point3DAlg 量测算法层（C++） | 20+ | 7.5~7.6 节 |
| BusinessAlg C API | 1 | 第 8 章 |
| ComUI 节点 | 83（image2d 56 + point3d 25 + business 2） | 第 9 章 |

## 4. CommonAlg —— 公共底座

最底层公共能力：JSON / 文件 / 日志。全部函数失败返回空/false 或默认值，不抛异常。头文件位于 `src/CommonAlg/include/`。

### 4.1 JSON 读取（`CommonAlg_Json.h`）

内部使用 nlohmann_json，带 GBK 容错（Juxin 配置文件可能是 GBK 编码）。

**编码转换三函数**

| 函数 | 原理与用法 |
|------|-----------|
| `bool CommonAlg_IsValidUtf8(const std::string& s)` | 校验整串是否为合法 UTF-8（含多字节序列校验，ASCII 恒合法）。用于判定输入编码。 |
| `bool CommonAlg_GbkToUtf8(const std::string& gbk, std::string& utf8)` | GBK(CP936) → UTF-8；非 Windows 平台或转换失败返回 false。 |
| `bool CommonAlg_ToUtf8(const std::string& bytes, std::string& utf8)` | 自动编码归一：UTF-8 BOM 去 BOM、合法 UTF-8 原样、其余按 GBK 转 UTF-8。 |

**`JsonDoc` / `JsonValue`** —— load 一次、逐层取值，缺键走默认值语义。

```cpp
JsonDoc doc;
if (!doc.load(path)) { /* 文件不存在或解析失败 → 空文档 */ }
double v   = doc["scanpulses"].float_(0.0);      // 缺键/非数值 → 默认值
std::string s = doc["LensRatio"].string_();      // 缺键 → ""
auto a = doc["scaleXYZ"].array();                // 数值数组（非数值元素跳过，不填 0）
auto g = doc["compensate_All"].group(1);         // 二维数组第 1 组
auto row = doc["Coordinate 3D"].at(i);           // 数组第 i 个元素（越界 → 空值）
size_t n = doc["Coordinate 3D"].size();          // 元素个数（非数组 → 0）
```

- `bool load(const char* path)`：读文件 → 检测编码 → 转 UTF-8 → 解析；NULL 按空串处理。
- `JsonValue` 方法：`has()`（键存在且非 null）、`float_(def)`、`string_(def)`、`array()`、`group(idx)`、`at(i)`、`size()`。
- **关键设计**：`array()` 对非数值元素**跳过而非填 0**——0 在几何数据里是合法值，静默填 0 会把解析错误伪装成真实数据。所有取值不抛异常。

### 4.2 文件与目录（`CommonAlg_FileUtil.h`）

跨平台、零第三方依赖，失败返回空/false。

| 函数 | 原理与用法 |
|------|-----------|
| `vector<string> CommonAlg_ListFiles(folder, ext)` | 列出目录下指定后缀文件（按文件名排序 = 自然扫描顺序）；ext 含点如 `.dat`，空串 = 全部。扫描数据帧顺序依赖此排序。 |
| `bool CommonAlg_ReadFile(path, out)` | 整文件读为字符串（二进制读，不转编码）。 |
| `bool CommonAlg_WriteFile(path, data)` | 覆盖写（父目录须已存在，不自动创建）。 |
| `bool CommonAlg_AppendFile(path, data)` | 追加写（文件不存在则创建）。 |
| `bool CommonAlg_FileExists(path)` / `DirExists(path)` | 存在性判断（FileExists 仅普通文件，不含目录）。 |
| `bool CommonAlg_MakeDir(path)` | 创建目录（含多级父目录），已存在视为成功。 |
| `string CommonAlg_FileName/FileStem/DirName/Extension(path)` | 路径分解：文件名含扩展 / 主干 / 目录部分 / 扩展名（含点）。 |
| `string CommonAlg_JoinPath(dir, name)` | 拼路径（自动补 `/`，不处理 `..`）。 |
| `string CommonAlg_ReplaceExtension(path, ext)` | 换扩展名（`/a/c.dat` + `.xml` → `/a/c.xml`）。 |

### 4.3 日志（`CommonAlg_Log.h`）

轻量分级日志，线程安全，格式固定便于 grep。

- 级别枚举 `CommonAlg_LogLevel`：Trace(0)/Debug(1)/Info(2,默认)/Warn(3)/Error(4)/Off(5)。
- 配置：`LogSetLevel(level)` / `LogGetLevel()` / `LogSetFile(path)`（追加写，空串关闭文件输出）/ `LogCloseFile()`。
- 底层导出函数 `CommonAlg_LogWrite(level, file, line, fmt, ...)`：真正的写日志入口；一般**不直接调用**，由 `COMMONALG_LOG_AT(lvl, ...)` 宏判级后转发（自动填 `__FILE__`/`__LINE__`）。若需自定义级别包装可基于该宏实现。
- 输出宏：`LOG_TRACE/DEBUG/INFO/WARN/ERROR(...)`（printf 风格）；带模块前缀别名 `CALG_LOG_*` 避免与 glog/spdlog/Qt 冲突。
- **原理**：宏先判级再格式化，低于当前级别的日志零格式化开销。格式 `[2026-11-05 14:03:22.123][INFO ][文件:行] 消息`。未设文件时只输出 stderr。

## 5. ShapelyAlg —— 基础算子库（C++）

**定位**：纯二维/三维几何与图像/点云**基础算子库**，无业务语义。唯一入口头 `ShapelyAlg.h`（含全部子模块与适配层），完整接入见 `src/ShapelyAlg/README.md`。

**六个组成部分**：

| 子模块 | 引擎 | 实现位置 | 职责 |
|--------|------|----------|------|
| Types.h | 无 | 头文件 | Point2d/3d、BoundingBox2d、AABB3d、OBB3d 原生结构（static_assert 布局契约） |
| Geom | GEOS | Pimpl | 二维几何构造/布尔/拓扑/度量/WKT·GeoJSON·DXF |
| Stereo | 纯数学 | Pimpl | 三维点集容器：AABB/OBB/距离/2.5D 桥接 + KdTree3 |
| ImageProcessor | OpenCV | 静态类 | 二维图像原子算子 24 组约 90 接口 |
| CloudProcessor | PCL | 模板类 | 三维点云算子 11 组约 90 接口（显式实例化白名单） |
| CloudIO / MeshIO / HeightMapIO | PCL/自实现 | 静态类 | 点云/网格/高度图文件读写 |

### 5.0 全局约定与快速上手

| 约定 | 说明 |
|------|------|
| 错误处理 | 全库不抛异常；失败返回空对象/0/-1/false/nullptr |
| 不可变性 | 布尔/形变运算返回新对象，原对象不变 |
| RAII | 析构自动释放底层资源；禁拷贝、只可移动（防 Double Free） |
| 鸭子类型 | 工厂模板只要求 `.x/.y`（3D 加 `.z`）成员，cv::Point 系/自定义结构直接可用 |
| BoostCompat 垫片 | 任何 .cpp 直接 include `<pcl/io/*.h>` 前必须先 include `BoostCompat.h`（Boost 1.68 + MSVC STL 的 seekpos C2039 垫片）；经 CloudIO.h 使用则库内已处理 |
| 模板白名单 | CloudProcessor/CloudIO 只对 `pcl::PointXYZ / PointXYZI / PointXYZRGB` 显式实例化 |

```cpp
#include "ShapelyAlg.h"
using namespace shapely;
Geom box = Geom::createPolygon(pts);
Geom cir = Geom::createCircle(0, 0, 10);
double a = cir.intersection(box).area();
Stereo st = Stereo::createFromPoints(pts3d);
AABB3d bb = st.getAABB();
auto cloud = CloudProcessor<pcl::PointXYZ>::filterVoxelGrid(src, 0.01);
```

### 5.1 Types.h —— 原生数据结构

| 结构 | 字段 | 原理/契约 |
|------|------|-----------|
| `Point2d` | `x, y` (double) | 二维点，也作 Geom 顶点输出载体 |
| `Point3d` | `x, y, z` | 三维点，z = 高度方向 |
| `BoundingBox2d` | `min_x/min_y/max_x/max_y, valid` | 2D AABB；`width()/height()` 取边长 |
| `AABB3d` | `min_x..max_z, valid` | 3D 轴对齐盒；`volume()` 三边乘积；`intersects(o)` 三轴投影重叠（边界接触算）；`contains(o)` 完全包含 |
| `OBB3d` | `center, extents[3], rotation[9], valid` | PCA 有向盒：extents 为半长，rotation 第 d 行 = 第 d 主轴；`volume()` = 8×三半长乘积；`intersects` 用 SAT 15 轴分离判定，`contains` 把 o 的 8 角点变换到本盒主轴系判定 |

`OBB3d` 被 `Stereo::getOBB`、`CloudProcessor::measureOBB`、`extractCropOBB` 共用；点变换到盒局部系用 `p_local[d] = rotation[d]·(p − center)`。所有结构经 `static_assert` 锁定平凡可拷贝/标准布局与 sizeof 上限（防布局漂移）。

### 5.2 Geom —— 二维几何引擎

**设计约束**：公共头零 GEOS、Pimpl 隔离、静态工厂强制声明几何意图、算子原子化、不可变、RAII 只移动、鸭子类型输入（3D 自动丢 Z）。

#### 5.2.1 通用功能（点/线/面均可）

| 接口 | 原理与使用 |
|------|-----------|
| `bool isEmpty()` | 构建失败或空对象判定。所有算子对空对象安全（数值返回 0/-1、布尔 false、运算返回空对象）。 |
| `string wkt()` | 输出 OGC WKT（如 `POLYGON ((0 0, 4 0, 4 4, 0 4, 0 0))`）；调试/落盘/GIS 交换；空对象空串。 |
| `string toGeoJSON()` | RFC 7946 子集几何对象（含孔洞环），上位机/前端可解析。 |
| `string toDXF()` | DXF R12 ASCII ENTITIES 段（Point→POINT，线/环/面→LINE），CAD 交换最小公共子集。 |
| `string typeName()` | GEOS 类型名（`Point`/`LineString`/`Polygon`/`MultiPolygon`…），空对象 `"null"`。 |
| `BoundingBox2d bounds()` / `toRect2d()` | 轴对齐包围盒；后者是语义别名（"取 ROI 裁图"场景）。 |
| `vector<Point2d> getExteriorPoints()` | 外壳顶点（Polygon 闭合、孔洞忽略；Multi 展开）。渲染/导出用。 |
| `vector<Geom> splitParts()` | 多体拆单体。union 不相交区域得 MultiPolygon 后逐区域取 `area()`（本库多边形度量只对单体有意义）。 |
| `double distanceTo(Geom& other)` | 最短二维距离（同单位，相交=0）；-1 = 空/失败。 |
| `Geom makeValid()` | GEOS MakeValid 修复自交/重复边；findContours 自交轮廓先修复再布尔/取面积。 |
| `string isValidReason()` | `"Valid Geometry"` 或带位置的诊断（如 `Self-intersection[...]`）。 |
| `static string lastError()` | 线程局部最近 GEOS 诊断。**用途**：运算结果 `isEmpty()` 时，`lastError()` 非空 = 拓扑失败，空 = 真空结果（真不相交）。布尔/形变运算入口清空，WKT 解析失败也写入。 |
| `Geom transformed(a,b,tx,c,d,ty)` | 2D 仿射 `x'=a·x+b·y+tx, y'=c·x+d·y+ty`。平移 `(1,0,tx, 0,1,ty)`、绕原点旋转 `(cos,-sin,0, sin,cos,0)`、缩放 `(sx,0,0, 0,sy,0)`。 |
| `bool intersects/touches(other)` | 相交（DE-9IM，边界接触算）；邻接（共边但不重叠）。 |
| `bool isValid()` | GEOS 有效性；自交面 false，此时 `area()` 语义不可靠。 |
| `Geom simplify(tolerance, keepTopology=false)` | Douglas-Peucker 抽稀； OpenCV 密集轮廓转 Geom 前先抽稀，否则布尔显著变慢；拓扑保持版结果合法稍慢。 |

#### 5.2.2 点专属 / 线专属 / 面专属

| 接口 | 原理与使用 |
|------|-----------|
| `double getX()/getY()` | 点坐标；非 Point 类型返回 0（严格按类型分派，不取包围盒）。 |
| `bool within(lineOrPolygon)` | GEOS Within：点在线上/面内 true，面**边界上 false**（需含边界业务层对目标面微量 buffer）。 |
| `double length()` | 折线总长；MultiLine 总长、Polygon 周长、点 0。 |
| `bool crosses(other)` | 拓扑交叉（线穿线、线穿面内部）；仅端点相接/共线重叠不算。 |
| `double area()` | 面积（合法面恒正，平方单位）；MultiPolygon 总面积；非面 0。 |
| `Point2d centroid()` | 面积加权质心；凹多边形质心可能在面外（数学事实非 bug）。 |
| `bool contains(other)` | GEOS Contains：other 无点在 exterior 且至少一点在 interior；沿边界的几何不算包含。 |
| `Geom intersection/unionWith/difference(other)` | 交/并/差，返回新对象；不相交返回空几何（非空指针）。 |
| `Geom buffer(dist, quadSegs=8)` | 外扩(dist>0)/内缩(dist<0)；quadSegs 每 1/4 圆弧逼近段数（默认 8）。含边界判定用 `buffer(1e-6)` 微扩。 |
| `Geom convexHull()` | 最小凸包；点集共线退化为线/点。 |
| `int numInteriorRings()` / `vector<vector<Point2d>> getInteriorRings()` | 内环数/顶点（仅 Polygon，MultiPolygon 返回 0）。 |
| `bool nearestPoints(other, out_a, out_b)` | 最近点对（相交时重合于交线）；false = 空/失败。 |
| `bool isWithinDistance(other, dist)` | 距离 ≤ dist，GEOS 原生短路（比 distanceTo 后比较快）。 |

#### 5.2.3 静态工厂（鸭子类型模板）

| 接口 | 原理与使用 |
|------|-----------|
| `createPoint(x, y)` / `createPoint(p)` / `createPoint(flat)` | 从数值/含 `.x/.y` 结构/扁平数组（取前两元素）创建点。 |
| `createLine(pts)` / `createLineFromFlat(flat)` / `createLineFromNested(nested)` | 按序连线不闭合；扁平 `[x1,y1,...]` 两两配对；嵌套内层取 [0][1]。少于 2 点返回空。 |
| `createPolygon(pts)` / `createPolygonFromFlat` / `createPolygonFromNested` | **自动闭合**（首尾不一致补点；GEOS ring 闭合是硬性要求，此处兜底）；有效顶点 < 4 返回空。 |
| `fromWKT(wkt)` | 解析任意 OGC 几何；失败返回空对象不抛异常。 |
| `createCircle(cx,cy,r, max_error=1e-4, segments=0)` | 离散为 N 边形（圆属性不保留）；自适应分段 `θ=2·acos(1-e/r), N=ceil(2π/θ)`，segments>0 强制并截断 [8,4096]。 |
| `createEllipse(xc,yc,a,b,theta_deg, max_error, segments)` | 椭圆离散；精度按长半轴（最坏曲率口径）。 |
| `createPolygonWithHoles(shell, holes)` | 带孔面：面积/包含/相交自动扣孔（普通 createPolygon 只能表达外轮廓）。 |
| `unaryUnion(vector<const Geom*>)` | 批量一元并集；GEOS 一次处理避免中间碎片化，nullptr/空对象忽略。 |

**示例**：

```cpp
Geom ring = Geom::createPolygonWithHoles(shell, {hole});
// ring.area() = 1200-100 = 1100；ring.contains(孔内点) = false
Geom merged = Geom::unaryUnion({&d1,&d2,&d3});
for (const Geom& part : merged.splitParts()) double a = part.area();
```

#### 5.2.4 PreparedGeom —— 预处理几何（空间索引缓存）

**原理**：一个几何（如 ROI 面）面对成百上千个几何反复做相交/包含判定时，普通谓词每次重建索引；Prepared 把索引建一次缓存，重复判定快约一个数量级。内部持有源几何移动入副本（`base_` 保活，因 prepared 结构引用基础几何指针）。

```cpp
PreparedGeom roi = PreparedGeom::prepare(roiPoly);
for (const Geom& defect : defects) if (roi.intersects(defect)) ++hit;
// 判定：intersects / contains（严格内部）/ covers（含边界）/ distanceTo
```

单对象不可跨线程并发（与 Geom 同）。

### 5.3 Stereo —— 三维点集与空间索引

**设计**：纯三维、无业务语义、Pimpl、RAII 只移动、2.5D 桥接。

| 接口 | 原理与使用 |
|------|-----------|
| `isEmpty()` / `size()` / `getPoints()` | 空判定/点数/导出全部点（拷贝）。 |
| `getZBounds(min_z, max_z)` | 提取 Z 范围；空点集置 0。 |
| `filterByZRange(min_z, max_z)` | 高度区间过滤，返回新对象（原对象不变）。BusinessAlg 区域占比用它做缺陷高度切片。 |
| `getAABB()` / `getOBB()` | AABB 三轴独立 min/max；OBB 用 PCA 主成分取三主轴、投影求极值（点数 <3 返回 invalid；第三轴 180° 等价解无影响）。 |
| `getAABBVolume()` / `getOBBVolume()` | 体积（mm³）；OBB 通常显著小于 AABB（更贴合）。 |
| `getCentroid()` | 各轴算术平均；工件系原点/旋转中心的自然选择。 |
| `minDistanceTo(other)` | 两点集最近欧氏距离（KD 树加速 O(n·log m)），空返回 -1；反复查询同一 other 应复用 KdTree3。 |
| `findClosestPair(other, pt_self, pt_other)` | 最近点对（干涉检查/对齐验证）。 |
| `hasCoincidentPointWith(other, tolerance)` | 是否存在重合点对（距离 ≤ 容差，传物理精度如 1e-3）。 |
| `meanNearestNeighborDistance()` | 平均最近邻距离（KD 树）；点云密度自适应选 radius/k 的依据；-1 = 空/点数 <2。 |
| `static distanceToPlane(p, plane[4])` | 点到平面 ax+by+cz+d=0 有符号距离；法向不需单位化（内部除 \|n\|）；\|n\|=0 返回 0。 |
| `static distanceToBox(p, box)` / `pointInAABB(p, box)` / `pointInOBB(p, box)` | 点到 AABB 距离（盒内=0）；点在 AABB 内（含边界）；点在 OBB 内（主轴系逐轴 \|p_local[d]\| ≤ extents[d]）。 |
| `projectTo2D()` | 剥 Z，XY 点集 → Geom 凸包多边形（<3 点返回空）；2.5D 桥接，可继续做全部 Geom 面运算。 |
| `transform(matrix16)` / `translate(dx,dy,dz)` | 应用 4×4 行主序刚体变换（配准结果应用端）/平移；返回新点集。 |
| `static invertTransform(matrix16, out)` | 4×4 求逆（高斯消元+部分主元，奇异/非有限 false）；工件系→扫描系。 |
| `static composeTransform(B, A, out)` | 串联 `out = B·A`（先 A 后 B）；粗对位与精配准合成单次变换。 |

**静态工厂**：`createFromPoints(pts)`（鸭子类型）、`createFromFlatArray(flat)`（三元组）、`createFromNestedArray(nested)`、`createFromBox(AABB3d/OBB3d/六边界值)`。PCL 点云用 `StereoPCLAdapter::createFromCloud(cloud)`（只提 xyz）。

#### KdTree3 —— 三维空间索引

**原理**：中位数切分建平衡树（平均 O(n log n)），最近邻/半径/K 近邻查询带剪枝。对同一目标点集反复查询时建树一次，避免 `minDistanceTo` 单次调用的重复建树开销。

```cpp
KdTree3 tree; tree.build(pts);          // 空点集返回 false
int idx; double dist;
tree.nearest(q, idx, dist);            // 最近邻（行号+欧氏距离）
tree.knn(q, 10, ids, dists);           // K 近邻（有界堆+剪枝，升序，k>点数取全部）
tree.radiusSearch(q, 2.0, ids, dists); // 半径内全部点（含边界），按距离升序
```

#### 5.5.8 tree / surface 空间索引与表面重建

**tree**：`treeKdTreeKNN(q,k,idx,dist)`（按距离升序）、`treeKdTreeRadiusSearch(q,r,idx,dist)`、`treeOctreeVoxelSearch(q,idx,res=1.0)`、`treeOctreeChangeDetection(c1,c2,res,new_idx)`（res≤0 拒绝，否则 octree 挂死）。

**surface（统一法线约定）**：所有需法线的重建接口要求法线一一对应、自动剔除 NaN/Inf/零长法线、有效法线 <50% 直接 `valid=false`；重建前先用 `featureOrientNormals*` 统一朝向。

| 接口 | 原理与使用 |
|------|-----------|
| `surfaceConvexHull(src)` | 最小凸包（点云）；平面点集返回 2D 凸包轮廓。 |

| `measurePointToMeshSignedDistance(src, mesh)` | 带符号距离（内负外正）：精确最近距离 × 射线奇偶符号；**仅闭合网格符号有物理意义**。 |

## 6. Image2DAlg —— 2D 图像模块（C API）

**定位**：`ShapelyAlg::ImageProcessor` 的上层封装——图像算子一律复用基础库实现，本层只负责参数语义（通道/尺寸/模式）、C 容器与 cv::Mat 转换、测量结果结构组装。权威头 `src/Image2DAlg/include/Image2DAlg_api.h`（当前版本 2.2.0，73 个通用算子：处理 17 + 特征 14 + 测量 37 + 跟踪配准立体 5；2.1.0 新增特征链路拆分五接口——检测/描述/匹配/几何估计可独立复用，与 ORBAlign 一站式并存；2.2.0 新增特征扩展——检测+描述一体三接口/斑点/一站式匹配，与跟踪、配准立体五接口）。

**通道语义**：`Image2DAlg_Image.channels` 支持 1(灰度)/3(BGR)/4(BGRA)，data 紧排（行步长 = width×channels，无对齐填充）。
- 通用算子保持输入真实通道数（1→1、3→3、4→4，alpha 随通道参与运算）。
- 天然单通道算子输出 1 通道：ToGray / Threshold / Canny / Sobel / Enhance(method=0) / HSVThreshold。
- **唯一例外** `ReadImage` 固定输出 BGRA（既有宿主契约，不改）。

**错误码**：`0` 成功；`-1` 空指针/空图；`-2` 多语义——ReadImage 打开失败，特征/匹配/估计族（ORBAlign / ComputeDescriptors / MatchFeatures / DetectAndMatch / EstimateAffinePartial / FindHomography）为特征或匹配不足/无法求解，跟踪配准族（FindTransformECC / SolvePnP）为不收敛·相关性不足/求解失败（平坦图正常，FastFeatures/BriskFeatures 等检测接口无检出返回 0 不报错；CalcOpticalFlowPyrLK 不使用 -2）；`-3` 通道数/模式/参数不支持；`-4` 内存不足；`-99` OpenCV 内部异常（C 边界统一捕获）。

### 6.2 通用处理算子（image → image）

参数语义复杂者给出要点，详细模式枚举见头文件注释。

| 接口 | 原理与使用 |
|------|-----------|
| `ToGray(in, out)` | BGR→灰度（0.114B+0.587G+0.299R），丢弃 alpha；1 通道输入原样拷贝；输出 1 通道。 |
| `Gamma(in, gamma, out)` | LUT 查表 `255·(v/255)^(1/gamma)`，O(1)/像素；gamma<0.05 钳制为 0.05；1.0 恒等、>1 提亮、<1 压暗；输出通道同输入。 |
| `Threshold(in, mode, thresh, maxval, block_size, C, out)` | 输出 1 通道；mode 0 固定二值/1 反二值/2 OTSU（双峰直方图）/3 自适应均值/4 自适应高斯（光照不均用 3/4）；block_size 偶数自动补奇最小 3；彩色先转灰度。 |
| `Binarize(in, mode, thresh, thresh2, maxval, mid_val, block_size, C, invert, out)` | 统一二值化，独立于 Threshold（mode 0~4 语义一致）：5 TRUNC（保留灰度层次）/6 TOZERO/7 TOZERO_INV/8 双阈值区间内前景/9 区间外前景/10 三值化（low/high/mid）；invert 对所有 mode 生效（v→255−v）；thresh2≥thresh 否则 -3。 |
| `Blur(in, method, ksize, sigma1, sigma2, out)` | method 0 高斯/1 中值/2 双边；ksize 自动补奇（双边=邻域直径，≤0 取 5）；sigma1 高斯 X/双边 sigmaColor，sigma2 高斯 Y/双边 sigmaSpace；4 通道双边拆 BGR 保 alpha。 |
| `Morphology(in, op, shape, ksize, iterations, out)` | op 0 腐蚀/1 膨胀/2 开/3 闭/4 梯度/5 顶帽/6 黑帽（与 cv::MORPH_* 同值）；shape 0 矩形/1 十字/2 椭圆；ksize 自动补奇，iterations<1 按 1。开去噪、闭填孔、梯度取轮廓。 |
| `Canny(in, t1, t2, out)` | 滞后阈值边缘，输出 1 通道 0/255；t2 经验 2~3 倍 t1；彩色先转灰度。 |
| `Sobel(in, dx, dy, ksize, out)` | 输出 \|梯度\| 缩放 0~255（内部 CV_16S 求导取绝对值，避免负梯度截断）；dx+dy≥1 否则 -99；ksize 1/3/5/7。 |
| `Resize(in, w, h, interpolation, out)` | 目标尺寸 ≤0 → -3；插值 0 近邻/1 线性/2 立方/3 面积/4 Lanczos4。 |
| `Crop(in, x, y, w, h, out)` | ROI 裁剪，越界钳制到图内；与图无交集（空结果）→ -3。 |
| `Rotate(in, angle, scale, interpolation, out)` | 绕图中心逆时针 angle 度 + scale 缩放，输出同尺寸；越界填黑。 |
| `Enhance(in, method, clip_limit, tile_size, out)` | method 0 全局直方图均衡（输出 1 通道）/1 CLAHE（输出同通道，彩色走 Lab 亮度、4 通道保 alpha）；clip 典型 2~4，tile≤0 取 8。 |
| `HSVThreshold(in, h_lo,h_hi,s_lo,s_hi,v_lo,v_hi, out)` | 输出 1 通道 0/255 掩膜；h∈[0,180]、s/v∈[0,255]；**须彩色输入**（灰度 → -3）；红色跨 0 需两次调用取并集。 |
| `HSVThresholdWrap(...)` | wrap 版：h_lo>h_hi 时自动按 `[h_lo,180]∪[0,h_hi]` 环绕（红色跨 0 一跳搞定）；h_lo≤h_hi 时等价 HSVThreshold。 |
| `AbsDiff(in1, in2, out)` | 逐像素差绝对值（批板差分，AOI 检出核心）；两图尺寸/通道必须一致否则 -3。 |
| `WarpAffine(in, m[6], w, h, interpolation, out)` | 仿射变换；**M 为 src→dst 前向映射**（cv::warpAffine 默认语义，非 WARP_INVERSE_MAP）——dst(x,y) 采样自 src(M⁻¹·[x,y,1]ᵀ)，越界填黑；M 为 2×3 行主序（可取 cv::getRotationMatrix2D / getAffineTransform 输出或 estimate_transform/feature_align 消息的 m）；标定对齐用。 |
| `WarpPerspective(in, m[9], w, h, interpolation, out)` | 透视变换；M 为 3×3 行主序。 |

### 6.4 特征点 / 多边形 / 对位（2.0.0 / 2.1.0 / 2.2.0 新增）

**特征链路拆分（2.1.0 新增）**：与 ORBAlign 一站式并存——检测（FastFeatures）/ 描述（ComputeDescriptors）/ 匹配（MatchFeatures）/ 几何估计（EstimateAffinePartial / FindHomography）拆为独立接口，关键点可来自 FAST/Harris/GoodFeatures 或外部跟踪器，一次检测可多次匹配。

| 接口 | 原理与使用 |
|------|-----------|
| `FastFeatures(in, threshold, nonmax_suppression, Point2f** out, count)` | FAST 角点检测（圆周连续像素比较，比 Harris 快一个数量级，适合实时/视频前处理）；threshold 灰度差阈值（典型 10~40，≤0 → -3）；nonmax_suppression 非 0 开启非极大值抑制去重；彩色先转灰度；无检出时 \*out=NULL、count=0 仍返回 0（纯平坦图正常不是错误）；释放 `FreePoint2f`。 |
| `ComputeDescriptors(in, pts, count, type, n_features, Descriptors* out)` | 关键点描述子计算；type 0=ORB（二进制 32B）/1=BRISK（二进制 64B）/2=AKAZE（二进制 61B）/3=SIFT（浮点 128 维，OpenCV 4.4 已进主库 features2d 无需 contrib），越界 → -3；n_features 仅 ORB 有效（≤0 取默认 500），其他类型忽略；count≥1 否则 -3；关键点须在图像内（越界 → -2；贴边点经内部 64px BORDER_REPLICATE 扩图采样可正常计算，与内部点结果一致——review 修正，此前 8~15px 贴边点会产出不可复现描述子）；AKAZE 对外部关键点统一按基尺度（原始分辨率尺度空间层）计算描述子（class_id 统一置 0）；**校验失败（-1/-2/-3）时不动 out 结构体**（调用方已分配的 data/fdata 不丢失，先 Free 再复用即可）；**匹配时两套描述子 type 必须严格一致**；out 由调用方分配、库填充字段，data/fdata 用 `FreeDescriptors` 释放（结构体本身归调用方）。 |
| `MatchFeatures(d1, d2, pts1, pts2, ratio, OrbMatch** out, count)` | BFMatcher kNN(k=2) + Lowe 比率测试（保留 d1 < ratio·d2）；二进制描述子（ORB/BRISK/AKAZE）用 Hamming 距离、浮点（SIFT）用 L2；d1/d2 的 type/dim/is_float 必须一致（否则 -3）；pts1/pts2 与描述子行序一一对应（即 ComputeDescriptors 的输入点集）；ratio∈(0,1) 否则 -3；**复用 `OrbMatch` 结构与 `FreeOrbMatches` 释放（未新增类型）**；返回 -2 匹配对数 <2（平坦图正常）。 |
| `EstimateAffinePartial(matches, count, ransac_reproj_threshold, double m[6], out_inliers)` | 部分仿射估计（4 自由度：旋转 + 各向同性尺度 + 平移）——比 ORBAlign 的全仿射（6 DOF）约束更强、抗误匹配更稳，工业视觉对位首选；输入 MatchFeatures/ORBAlign 的匹配对（count≥3 否则 -2）；threshold 像素典型 3.0（≤0 → -3）；m 为 in1→in2 的 2×3 行主序，可直接接 WarpAffine；内点数 ≥10 视为可靠。 |
| `FindHomography(matches, count, ransac_reproj_threshold, double h[9], out_inliers)` | 单应矩阵估计（3×3 透视变换，配合 WarpPerspective 做平面拼接/大视角对位）；count≥4 否则 -2，所有点共线等退化 → -2；h 为 3×3 行主序、方向 in1→in2（h[8] 归一为 1）；threshold 语义同 EstimateAffinePartial。 |

描述子容器：`struct Image2DAlg_Descriptors { int type, dim, is_float, count; unsigned char* data; float* fdata; }`——type 0=ORB/1=BRISK/2=AKAZE/3=SIFT；dim 为单描述子字节数（二进制）或 float 维数（SIFT 128）；is_float=1 读 fdata（count×dim 个 float）、0 读 data（count×dim 字节）；count = 描述子个数（= 输入关键点数）。data/fdata 由库 malloc、用 `Image2DAlg_FreeDescriptors` 释放（free 后各自置空，NULL 安全可重复调用）。

#### 6.4.1 特征扩展：检测+描述一体 / 斑点 / 一站式匹配（2.2.0 新增）

**`contrast_threshold` 映射表**（三个检测+描述一体接口的同一参数，语义随检测器变化）：

| 接口 | 映射目标 | ≤0 时的默认值 | 方向 |
|------|----------|---------------|------|
| `BriskFeatures` | BRISK::create 的 thresh（int 取整） | 30 | 越大检出越少 |
| `AkazeFeatures` | AKAZE::create 的 threshold（float） | 0.001 | 越小检出越多 |
| `SiftFeatures` | SIFT::create 的 contrastThreshold | 0.04 | 越大检出越少 |

| 接口 | 原理与使用 |
|------|-----------|
| `BriskFeatures(in, n_features, contrast_threshold, Point2f** out_points, int* out_count, Descriptors* out_desc)` | BRISK 特征检测+描述一次完成（尺度空间极值 + 二进制 64 字节描述子，旋转/尺度鲁棒、速度快）；彩色先转灰度；n_features **忽略**（BRISK 无上限参数）；out_points 库 malloc 配 `FreePoint2f`（无检出 \*out_points=NULL、\*out_count=0 仍返回 0，平坦图正常）；out_desc 调用方分配结构体、库填充字段（data/fdata 配 `FreeDescriptors`，结构体本身归调用方），**传 NULL = 只检测不取描述子**；错误码 0/-1/-4/-99。 |

| `BlobDetect(in, min_area, max_area, min_circularity, min_convexity, BlobFeature** out_blobs, int* out_count)` | 斑点检测（SimpleBlobDetector：灰度多阈值二值化 → 连通域 → 形状过滤聚合）。**与 FitCirclesFromBinary 的语义区分**：本接口 = 连通域形状过滤（多阈值聚合，按面积/圆度/凸性/惯性比筛选，快速定位圆点/焊盘）；FitCirclesFromBinary = 二值前景逐轮廓最小二乘圆拟合（精度更高、可选亚像素细化）——快速定位用本接口，精密测量用拟合接口。min_area/max_area ≤0 = 无下限/不设上限（同 ConnectedComponents 约定）；min_circularity/min_convexity >0 启用过滤、≤0 **显式关闭**（OpenCV 4.4 默认 Params 的凸性过滤开启 minConvexity=0.95，会滤掉一般光栅化圆的锯齿轮廓，故过滤状态由本接口参数显式决定）；其余用 SimpleBlobDetector 默认：暗斑（blobColor=0，亮斑请先反转）、灰度阈值 50~220 步进 10、惯性比 ≥0.1、重复性 ≥2；无检出 \*out_blobs=NULL/count=0 返回 0；释放 `FreeBlobFeatures`；错误码 0/-1/-3/-4/-99。 |

斑点容器（2.2.0 新增类型导出）：`struct Image2DAlg_BlobFeature { float x, y, radius; }`——斑点中心（像素）与半径（像素，直径/2——SimpleBlobDetector 的尺寸为斑点直径，含 1~2px 光栅化偏差）；数组由库 malloc，用 `Image2DAlg_FreeBlobFeatures` 释放（直接 free 指针本身，NULL 安全，调用方自行置空）。

### 6.5 相机标定（`Image2DAlg_Calib.h`，C++ API）

纯 C++ 手写实现（基于 Eigen 线性代数，OpenCV 仅用图像容器与角点检测结构）。命名空间 `image2d`。
导出面：13 处 `IMAGE2DALG_EXPORT`（10 个函数 + 3 个 POD 类型 `CameraIntrinsics`/`StereoExtrinsics`/`StereoRectify`）；下表按功能归并为 9 行，10 个函数全部覆盖（Mei 四函数两两并排、CalibSave/Load 并排）。

**Mei 鱼眼模型原理**：等距投影统一球面模型——世界点→单位球面→极坐标投影 `r = ξ + f·θ(ρ)`→畸变→像素；ξ∈[0,1]（0 针孔、1 纯双曲面镜）。单目用张正友法求初值 + Levenberg-Marquardt 精化；双目左右各自标定→立体对齐→Bouguet 立体校正。

#### 7.1.3 滤波 / 提取 / 变换（1.1.0，封装 `CloudProcessor`，PCL 守卫）

实现文件 `Point3DAlg_CloudOps.cpp`。三个接口共用点云计算族错误码口径（-1 空指针/空云；-2 空结果；-3 method 越界或 params 数量/取值不符；-4 内存不足；-99 PCL 异常）；params 为 double 数组，param_count = 有效个数。

#### 7.1.4 拟合 / 分割 / 搜索 / 通用度量（1.2.0 P1 批次，PCL 守卫）

实现文件 `Point3DAlg_CloudOps.cpp`。本节接口共用点云计算族错误码口径（0 成功（搜索 0 命中亦成功）；-1 空指针/空云；-2 空结果/退化/拟合失败；-3 method 越界或 params 数量/取值不符、capacity 不足；-4 内存不足；-99 PCL 异常）。**输出数组内存约定**：一级指针输出缓冲（out_coeffs / out_values）由调用方预分配（capacity 不足 → -3 并经 out_*_count 回填所需长度，**两段式调用**：先 capacity=0 查长度，再分配重调）；二级指针输出（out_inliers / out_segments / out_indices / out_dists 等）由本库 malloc，配套 Free* 释放（全部 NULL 安全）。

**`int Point3DAlg_FitModel(in, method, fit, distance_threshold, double* out_coeffs, int coeffs_capacity, int** out_inliers, int* out_inlier_count)`**：通用几何拟合。method 0=plane / 1=sphere / 2=cylinder / 3=circle3D / 4=cone；fit 0=RANSAC / 1=MSAC / 2=LMS(LMEDS)（映射 shapely::FitMethod——**注意与底层枚举顺序不同**，以 0=RANSAC/1=MSAC/2=LMS 为准）；distance_threshold 为局内点判定距离阈值（与坐标同单位，>0）。out_coeffs 布局（权威口径，对齐 CloudProcessor 各拟合输出）：

| method | 模型 | out_coeffs 布局 |
|--------|------|----------------|
| 0 | plane | [4] = a,b,c,d（ax+by+cz+d=0，\|n\|=1） |
| 1 | sphere | [4] = cx,cy,cz,r（球心 + 半径） |
| 2 | cylinder | [7] = px,py,pz（轴上一点）+ dx,dy,dz（单位轴方向，PCL SampleConsensusModelCylinder 系数顺序）+ r |
| 3 | circle3D | [7] = cx,cy,cz（圆心 3D）+ nx,ny,nz（圆平面单位法向）+ r（底层圆周残差 RMS 未暴露，可用 out_inliers 自行复算） |
| 4 | cone | [7] = ax,ay,az（锥顶点）+ dx,dy,dz（单位轴方向）+ 半开角（弧度，0~π/2） |

> 模型支持度（PCL 1.9 限制，底层自动回退不报错）：plane 三种 fit 均支持；sphere 支持 RANSAC/LMEDS（MSAC 回退 RANSAC）；cylinder/cone 仅 RANSAC（fit 被忽略）；circle3D 的 fit/threshold 复用其内部平面拟合口径。out_inliers = 局内点索引（相对 in->xyz 行号）——库 malloc int 数组经二级指针交回，用 `FreeBuffer` 释放，可传 NULL = 不需要内点（out_inlier_count 仍回填）；out_inlier_count 必填（NULL → -1）。-3 时回填所需系数长度（两段式）；-2 = 拟合失败/无局内点/退化（点数不足、投影点共线、圆锥不收敛等）。

**`int Point3DAlg_SegmentCloud(in, method, params, param_count, Point3DAlg_PointCloud** out_segments, int* out_segment_count)`**：分割与聚类，method 与 params 布局表（params 为 double 数组，数量不符 → -3）：

| method | 语义 | params 布局 |
|--------|------|------------|
| 0 | planeRANSAC 主平面分割 | [0]=distance_threshold（>0）。必填 1 个 |
| 1 | euclideanCluster 欧式聚类 | [0]=cluster_tolerance（>0）；[1]=min_size（≥1）；[2]=max_size（≥min）。必填 3 个 |
| 2 | dbscan 密度聚类 | [0]=eps 邻域半径（>0）；[1]=min_points 核心点最小邻居数（≥1，含自身）。必填 2 个 |
| 3 | regionGrowing 区域生长 | [0]=k_neighbors（≥3，兼作内部法线估计的 KNN 数）；[1]=smoothness_deg 法线夹角阈值（度，>0）；[2]=curvature_thresh（≥0）；[3]=min_size（≥1）；[4]=max_size（≥min）。必填 5 个 |
| 4 | planesMulti 多平面迭代 | [0]=distance_threshold（>0）；[1]=max_planes（≥1）；[2]=min_inliers（≥3）。必填 3 个 |

> out_segments 语义（库 malloc 数组 + 每段 xyz，**全部用 `FreeClouds(segments, count)` 释放**）：0 → 恒 2 段：[0]=主平面局内点、[1]=其余点（**可为空段 count=0**，调用方按下标配段无需分支；平面方程可用 FitModel 另取）；1 → 每簇一段（点数降序）；2 → 每簇一段（点数降序编号，噪声点丢弃；**输入含 NaN/Inf 点时自动剔除后聚类，坐标映射回原始点**）；3 → 每区域一段（点数降序，法线由本接口内部按 k_neighbors KNN 估计）；4 → 每平面局内点一段（按检出顺序 = 点数降序趋势）。无有效段 → -2（DBSCAN 全噪声、平面拟合失败等）。

**`int Point3DAlg_KnnSearch(in, const double query[3], k, int** out_indices, float** out_dists, int* out_count)` / `Point3DAlg_RadiusSearch(in, query[3], radius, ...)`**：空间索引近邻搜索（KdTree）。query 查询点 [x,y,z]（double，本层转 float 进 KdTree）；out_indices/out_dists 均为库 malloc，**用 `FreeSearchResult` 一次释放两缓冲**（不复用 FreeBuffer，避免二次释放歧义）；两者可传 NULL 表示不需要（count 仍回填）；out_dists 布局 = 与 out_indices 一一对应的**欧氏距离**（底层 KdTree 返回平方距离，本层开方——注意不是 PCL 原始口径），按距离升序；0 成功含 0 命中（半径内无点 → 0 成功 + \*out_count=0）；-3 = KnnSearch k≤0 / RadiusSearch radius≤0。

**`int Point3DAlg_MeasureCloud(in, other, method, params, param_count, double* out_values, int values_capacity, int* out_value_count)`**：通用度量（§13 输出字典口径），method 与输入/params/输出布局表：

| method | 语义 | 输入 | params | out_values 布局 |
|--------|------|------|--------|----------------|
| 0 | AABB | in=点云（≥1 点） | 无 | 6 [minx,miny,minz,maxx,maxy,maxz] |
| 1 | OBB | in=点云（≥3 点） | 无 | 15 [cx,cy,cz, ex,ey,ez(半长), R9 行主序(行=主轴)] |
| 2 | centroid | in=点云 | 无 | 3 [cx,cy,cz] |
| 3 | meanCovariance | in=点云（≥2 点） | 无 | 12 [mx,my,mz, c00..c22 行主序] |
| 4 | pointCloudDistance（逐点最近距离） | in=源点云；other=目标点云（必填，NULL → -1） | 无 | N（=in->count）——每点到 other 最近点的欧氏距离（非平方） |
| 5 | flatness 平面度 | in=点云 | [0]=distance_threshold（局内点阈值 >0），必填 1 个 | 3 [pv 峰峰值, sigma 局内点残差标准差（本层复算：\|残差\|≤threshold 者口径）, inlier_count] |
| 6 | planeAngle 两平面夹角 | in/other 忽略（可 NULL） | [0..3]=平面1 [a,b,c,d]；[4..7]=平面2 [a,b,c,d]，必填 8 个（法向零向量 → -3） | 1 [angle_deg 锐角口径 [0,90]] |
| 7 | planeIntersection 交线 | 同 method 6 | 同 method 6 | 6 [px,py,pz 交线上一点（最近原点）, dx,dy,dz 单位方向]（近平行 → -2） |

> capacity 不足 → -3（\*out_value_count = 所需长度，两段式）；-2 = 方法 7 两平面近平行 / 方法 3 点数不足 / 方法 5 平面拟合失败或局内点 <2。

#### 7.1.5 法线 / 特征 / 关键点 / 表面重建 / 网格 / HeightMap 桥接（1.2.0 P2 批次，PCL 守卫）

实现文件同 `Point3DAlg_CloudOps.cpp`，错误码同点云计算族口径（见 7.1.4 开头）。

**`int Point3DAlg_EstimateNormals(in, method, param, float** out_normals, int* out_count)`**：法线估计。method 0=KNN（param = 近邻个数 k，≥3）/ 1=radius（param = 搜索半径，>0；邻居上限固定 100，Open3D max_nn 语义；半径内不足 3 点 → 该点法线 = NaN，保留在输出中）。out_normals = 库 malloc float 数组，**N×4 布局**——每点连续 4 个 float [nx,ny,nz,curvature]（单位法向 + 曲率；底层 pcl::Normal 的曲率字段顺手带出，选 N×4 而非 N×3），用 `FreeBuffer` 释放；out_count = 点数 N（与输入一一对应）。

**`int Point3DAlg_ComputeFeature(in, desc_type, param, float** out_features, int* out_dim, int* out_count)`**：特征描述，desc_type 布局表：

| desc_type | 语义 | param | out_dim |
|-----------|------|-------|---------|
| 0 | FPFH 33 维直方图 | 特征计算半径（>0；内部先按 KNN k=10 估计法线——SoA 容器无法传入法线，固定口径） | 33 |

**`int Point3DAlg_DetectKeypoints(in, type, radius, threshold, Point3DAlg_PointCloud* out)`**：关键点检测。type 0=Harris3D（radius = 邻域搜索半径 >0；threshold = 响应阈值 ≥0，越小保留越多，非极大值抑制恒开启）/ 1=ISS3D（radius = salient_radius 显著性半径 >0，典型取点距数倍；threshold = non_max_radius 非极大值抑制半径 >0，典型 < salient_radius）。out = 关键点云（xyz 库 malloc，用 `FreeCloud` 释放）；0 个关键点 → -2。**数据注记（ISS3D）**：显著性条件要求邻域散布矩阵最小特征值严格 >0——无噪声的精确解析曲面（如理想圆柱/平面）上邻域严格共面 → e3 恒 0 → 恒 0 关键点（-2）；真实扫描或带噪合成数据不受影响。

**`int Point3DAlg_ReconstructSurface(in, type, params, param_count, Point3DAlg_Mesh* out_mesh)`**：表面重建，type 与 params 布局表（params 为 double 数组，数量不符 → -3）：

| type | 语义 | params 布局 |
|------|------|------------|
| 0 | convexHull 凸包 | 无参数（本层直接调 PCL ConvexHull 取面片——CloudProcessor::surfaceConvexHull 只回顶点云） |

| 3 | Poisson 泊松重建 | [0]=depth 可选（八叉树深度，默认 9，<2 → -3）；[1]=iso_divide 可选（默认 8，≤depth）；[2]=samples_per_node 可选（默认 1.0）。最多 3 个。法线由本接口内部估计并强制朝向一致化（见下） |

> **法线自动管线（type 3~7）**：本接口内部先按 KNN k=10 估计法线，再经 orientNormalsConsistentTangentPlane（MST 传播，k=30）统一朝向后传入底层重建——ShapelyAlg §9.12 强制约束"Poisson 前必须统一法线朝向"，对同样吃法线的 greedy/marchingCubes/gridProjection 一并执行。out_mesh 输出容器（实现统一先清零再填充），vertices/faces 库 malloc，用 `FreeMesh` 释放；重建失败（valid=false）/空网格 → -2。

**网格容器（1.2.0 新增）**：`struct Point3DAlg_Mesh { float* vertices; int vertex_count; int* faces; int face_count; }`——vertices 为 3V 个 float 交错；faces 为 3F 个 int（每面连续 3 个顶点索引，底层四边形面已统一扇形三角化，CloudProcessor meshFromPolygonMesh 同口径）；`FreeMesh`（NULL 安全）：free vertices + free faces 后全部清零，只用于本库分配的缓冲。

**`int Point3DAlg_MeshOp(const Point3DAlg_Mesh* in, op, params, param_count, Point3DAlg_Mesh* out_mesh, double* out_scalar, float** out_array, int* out_array_count)`**：网格处理与度量，op 与 params/出参分流表（数量不符 → -3；所需出参为 NULL → -1）：

| 1 | clusterDecimate 网格顶点聚类抽稀 | [0]=cell（>0 体素边长）。必填 1 个 | out_mesh |
| 2 | cropByOBB 网格裁剪 | params[0..14]=center xyz + extents xyz(半长>0) + rotation 9 行主序（行=主轴，与 ExtractCloud cropOBB 同约定）。必填 15 个 | out_mesh（保留三顶点全在盒内的面，重编号） |
| 3 | area 总表面积 | 无参数 | out_scalar（双精度） |
| 4 | volume 有向体积 | 无参数 | out_scalar（仅闭合水密网格有物理意义） |
| 5 | pointToMeshDistance 点到网格最近距离 | params=查询点列表 [x0,y0,z0, x1,y1,z1, ...]（param_count=3N，N≥1） | out_array/out_array_count：N 个距离（欧氏，`FreeBuffer` 释放；非有限查询点 → NaN） |
| 6 | faceNormals 面法线 | 无参数 | out_array=3F 个 float（out_array_count=F 条，每条 3 个单位分量，退化面=(0,0,0)，`FreeBuffer` 释放） |
| 7 | vertexNormals 顶点法线 | 无参数 | out_array=3V 个 float（out_array_count=V 条；相邻面面积加权平均，`FreeBuffer` 释放） |

> **out_array 设计说明**：Mesh 容器无顶点属性位，法线"写回 out_mesh 顶点属性"不可行——op 6/7 改为输出到独立 float 数组（out_array，`FreeBuffer` 释放），op 5 的逐点距离同走 out_array。-2 = 结果为空（0/1/2 输出网格无面片、输入网格无效）。

**`Point3DAlg_HeightMap` 容器与 3D→2D 桥接（1.2.0 新增）**——容器逐字段镜像 ShapelyAlg HeightMap（CloudIO.h/CloudProcessor.h 权威），拍平成 POD C 容器。数据为 float 高度格，宿主可直接按 width×height 单通道浮点图（对应 Image2DAlg 的 CV_32F 口径）使用——空格 = NaN，配合 mask（1=有点）区分"高度恰好为 0"与"无点"；转 8U 灰度显示由宿主按 cells+mask 自行映射（库不预压缩）。**坐标：col=(x−x0)/cell、row=(y−y0)/cell，row 0 = y 最小——imshow 显示时 Y 向下，与 Image2DAlg 图像坐标系一致**（HeightMap→Image2DAlg_Image 桥接时行序无需翻转）。

| 字段 | 含义 |
|------|------|
| `width` / `height` | 列数（X 方向栅格数）/ 行数（Y 方向栅格数） |
| `x0` / `y0` | 栅格 (0,0) 的 X / Y（= 有效点 x/y 最小值） |
| `cell` | 栅格边长（与坐标同单位） |
| `cells` | width×height 行优先 z 值（float）；空格 = NaN |
| `mask` | width×height；1=有点 / 0=空 |
| `valid` | 1 = 有效图 |

| 接口 | 原理与使用 |
|------|-----------|
| `CloudToHeightMap(in, cell, mode, Point3DAlg_HeightMap* out)` | 点云 XY 栅格化为高度图（3D AOI → 2D ImageProcessor 全部算子的桥）。cell 栅格边长（>0；总栅格数上限 2000 万，超出 → -2）；mode 0=每格取最高 z / 1=最低 z / 2=平均 z / 3=点计数密度（其他 → -3）；cells/mask 库 malloc 用 `FreeHeightMap` 释放；非有限坐标/高度的点自动剔除。-2 = 无有效点/超上限。 |
| `HeightMapToCloud(hm, Point3DAlg_PointCloud* out)` | 高度图反向点云化：每个有效格（mask=1）生成一个点，坐标取格心 x=x0+(col+0.5)·cell、y=y0+(row+0.5)·cell、z=cells 值（mode=3 密度图的 z 即计数值）；out 用 `FreeCloud` 释放。-1 = hm 结构字段不一致（cells/mask 为 NULL 或长度与 width×height 不符）；-2 = hm 无效（valid=0）/宽高 ≤0/无有效格。 |
| `ThicknessMap(top, bottom, cell, Point3DAlg_HeightMap* out)` | 厚度图：同一工件上/下表面两点云沿 Z 配对求差（板厚/锡膏厚度测量）。栅格范围 = 两云有效点 XY 包围盒并集；上云每格取最高 z、下云每格取最低 z；同格双有效 → 厚度 = zTop−zBottom（cells）、mask=1，任一缺失 → NaN/0。cell>0，上限同 CloudToHeightMap。 |

释放函数 `FreeHeightMap`（NULL 安全）：free cells + free mask 后全部清零，只用于本库分配的缓冲。

### 7.3 SICK 深层句柄族 C 接口（`Point3DAlg_SickApi.h`，1.1.0 新增）

把 SickReader C++ 类已有能力（原始图/编码器/行中心 Y/强度图/逐点强度/拼接质量自检/FOV 结构化框）暴露给 C 宿主；本层只做 C 边界（句柄生命周期 + 缓冲拷贝 + try/catch），不含算法。**不依赖 PCL，任何构建下恒导出**。

**错误码口径**：与既有 ReadSickCloud 家族对齐（见 7.1 节双口径表 SICK 读取族行），**不使用**点云计算族的 -3=参数越界/-4=内存 全局约定，避免同 DLL 内歧义。特例：StitchQuality 的 threshold≤0 按参数越界报 -3。

|------|-----------|

### 7.4 SickReader 类（C++ 读取核心）

**数据布局与换算链路**（已按 Z:\ScanImage\3D 真实数据逐字节验证）：
- `.dat` 平面布局：`[N × 5120B 高度图（2560×uint16 小端，0=无效）] [N × 20B 编码器记录（5×int32：A, 0x40000000, B, C, 0）]`。A 为扫描轴编码器值，逐行 ±scanStep，蛇形往返由方向翻转体现。
- 同名 `.xml`（icon_data_format）：**预留未读**，换算完全依赖 recipe/common json。
- `Scan3DPart*.json "Coordinate 3D"`：`[[x1,x2,y,0],...]` 每扫描行（pass）一条，y 为行中心。

**拼接原理**：单相机——每个原始行旋转 90° 成拼接图一列（列号 = (A−aMin)/scanStep），蛇形 down 行内镜像，pass 间按行中心 Y 排布；`z_mm = raw×z_scale + z_offset − diff(col)`。多相机（双相机交织）——各相机先单机拼接→按起始编码器脉冲对齐（左补 0）→按起始脉冲排序→列交织合并（第 k 列取第 k%N 台相机的第 k/N 列）→左右全零裁剪；交织后 x 步距 = 实测 scanStep×mmPulse / 相机数。

**两阶段加载**：阶段 1 只读编码器块建 FOV 结构（换行/裁剪/ROI 全确定）；阶段 2 多线程按 ROI 读 .dat 图像块。相机 0 原始数据懒构建（Raw()/Encoder() 首次调用才拼合，避免双相机 ~360MB 数据内存翻倍）。

| 接口（成员） | 原理与使用 |
|------|-----------|
| `Point3DAlg_SickReader(cfg)` | 构造接收 SICK 参数。任何一步失败抛 `std::runtime_error` 带人话描述（C++ 层）。 |
| `LoadRaw(folders, frame=-1)` | 加载原始图像；folders 每相机一个（如 3D 与 3D-2），单相机传 1 个；frame≥0 只读第 frame 帧，<0 读全部。单相机便捷重载 `LoadRaw(folder, frame)`。加载后 Width/Rows/RowY 立即可用，Raw/Encoder 懒构建。 |
| `DeviceCount()` | 相机数量（LoadRaw 后有效）。 |
| `GetDepth()` | 矫正拼接深度图 `StitchRows()×StitchCols()` 行主序（mm，0=无效，内部持有）；重复调用返回同一缓冲。 |
| `GetCloud(int* count=nullptr)` | SoA 点云（xyz 交错 float×3N，跳过 z=0 点）；x=col×(实测scanStep×mmPulse)/DeviceCount，y=(StitchRows()/2−row)×y_scale，z=深度图值；重复调用返回同一缓冲。 |
| `Raw()` / `Encoder()` / `Width()` / `Rows()` / `RowY()` | 相机 0 原始数据访问（懒构建）：uint16 原始高度 / int32 每行编码器值 / 每行轮廓像素数(2560) / 原始总行数 / 每个 pass 中心 Y。 |
| `HasIntensity()` / `GetIntensity()` / `GetCloudIntensity()` | 强度通道（GetDepth 后有效，新格式 .dat 才有）：与深度图同几何的 uint8 强度图（0 无效）/逐点强度（与点顺序一致）。格式判定：旧行距 5140B 无强度，新行距 7700B = 高度 2560×uint16 + 强度 2560×uint8 + 编码器 20B；二义性行距用编码器块 magic 0x40000000 回退。 |
| `StitchRows()` / `StitchCols()` / `FovBoxes(rects, ids)` | 拼接图尺寸 / FOV 在最终拼接图中的覆盖矩形 `{x,y,w,h}`（d 相机 j FOV 编号 = d*1000+j，可视标注用；GetDepth 后调用）。 |
| `StitchQuality(threshold, out)` | 拼接质量自检：多相机衔接带（物理同位置列在交织图中相邻）逐行配对求 z 差→pairs/dh_mean/dh_sigma/dh_max_abs/outlier/outlier_ratio（`Point3DAlg_StitchQualityResult`）；差值大 = 标定漂移/丢帧/同步异常；单相机（n<2）返回 false。 |

### 7.5 配准算法层（`tools/Point3DAlg_Regist.h`，纯函数）

**设计**：纯函数（显式传/返状态，兼容 ComUI"每次新建实例"）、变换统一 4×4 行主序 float[16]、底层走 `CloudProcessor`、零 UI 头。

### 7.6 量测算法层（`tools/`，纯函数、确定性）

**共同特征**：全确定性（Kåsa 代数拟合，非 RANSAC，可复现）、结果统一有限性校验（NaN 判失败）、数值内核共用 `FitUtil.h`（MedianOf / FitPlaneZ）、坐标单位 mm。

| 接口 | 原理与使用 |
|------|-----------|
| `DomeFitBase(cloud, params, base)` | 稳健基面：z=a·x+b·y+c 迭代修剪最小二乘（剔除 >中位数+3·MAD 的点，5 次），扣倾斜后取残差中位为零平面；返回法向/d/σ/内点数。点数<10 或退化 false。 |
| `DomeFit(cloud, params, bumps, base*)` | 拱形球顶 bump 拟合：基面→高度分离（>height_threshold）→欧式聚类（复用 CloudProcessor）→每簇 Kåsa 球闭式解 + 一次 MAD 修剪重拟合；高度 = apex − 基面（apex=c+R·n，比取最高点稳：单点噪声被球拟合平均）。结果按簇点数降序。false = 输入非法/基面失败/无簇。`Point3DAlg_DomeFitParams{height_threshold=0.02, cluster_tolerance=0.12, min_points=8, base_mad_factor=3, base_iterations=5, sphere_mad_factor=3, max_radius=1, min_radius=0.01, max_fit_rms=0.005}`。 |
| `DomeStatsOf(bumps)` | 高度统计（count/mean/stddev/min/max/p5/p50/p95）+ 共面性两口径：`coplanarity`=极差法(max−min，JEDEC 常用)、`fit_sigma`=对 (x,y,h) 拟合最佳面 `h=p·x+q·y+r` 的内点残差 RMS（剥离倾斜/翘曲，fit_p/fit_q 诊断翘曲向）。 |
| `BumpCompare(ref, test, params, out)` | 基准/被测 bump 一对一匹配（XY 最近贪心、冲突取更近者）+ 高度差 NG（\|dh\|>ng_threshold）；输出 matched/unmatched_ref(漏测)/unmatched_test(多出)/ng_count/ng_ratio/dh_mean/rms/max + diff_xy/diff_h/diff_ng（按差值降序）。`BumpCompareParams{match_radius=0.3, ng_threshold=0.02}`。 |
| `RegionPlaneFit(cloud, x,y,w,h, params, out)` | ROI 平面量测：XY 矩形（半开 [x,x+w)×[y,y+h)）内迭代修剪最小二乘（**双侧**剔除 \|残差−中位\|>factor·MAD，每轮从全点重建允许误删回归）；输出 `z=a·x+b·y+c`、height（ROI 中心 z）、平面度 PV（内点残差极差）、σ、内点数。稳健边界：minority 污染 ≤20% 可靠剔除（ROI 应以主平面为主）；点数<3 或共线 false。台阶差 = 两 ROI 的 height 相减。 |
| `CloudDiff(A, B, params, out, diff_cloud*)` | 金标准复检：两片 XY 栅格化（cell_size）每格 z 中位→共有格 diff=zB−zA（正=被测高）→统计 mean/σ/极值/超差(\|diff\|>阈值)占比；可选 XY 粗对齐（align_search>0 时 ±search 格域 RMS 搜索+重叠 70% 门槛+±2 格细化，精度 ≈±cell/2）。diff_cloud 每格一点（z=diff，伪彩看 NG 分布）。共同格=0 false。`CloudDiffParams{cell_size=0.1, min_points_per_cell=3, diff_threshold=0.02, align_search=0}`。 |
| `DetectCircles(cloud, z_low, z_high, params, circles)` | 高度切片圆/孔位：z∈[z_low,z_high] 切片（孔壁点保留、基面/顶面切除）→欧式聚类→每簇 Kåsa 代数圆拟合（中心化 3×3 法方程）+ 双侧 MAD 修剪重拟合；输出圆心 XY/半径/rms/mean_z/valid。圆壁应覆盖整圆（<180° 短弧 Kåsa 病态，圆心可能偏）；返回簇总数（含无效）、-1 参数非法、0 无切片点。 |
| `FitCircle2D(xy, count, mad_factor, iters, r_min, r_max, rms_max, out)` | 单簇圆拟合核心（XY 平面，xy 为 x,y 交错）；已有轮廓点直接拟合，不必走切片；valid=false 仍带数据供诊断。 |
| `Profile(cloud, x0,y0,x1,y1, params, out, profile*)` | 轮廓截面：取到线段垂距 ≤band 且投影落线段内的点→投影弧长 s 分格（bin_size）每格 z 中位→统计 z 范围及位置、相邻有效格最大跳变 `max_step`（台阶/落差）及位置。profile 每格 [s,z]。max_step 对噪声敏感（≈√2×噪声），台阶判定设工程阈值。云空/线段长 0/带内无点 false。 |
| `BumpReport(cloud, params, entries*, stats*)` | bump 全参数报表（一次性）：DomeFit 检出全部 bump→逐 bump 距顶 depth_ratio=0.35 处球冠截面圆拟合（半径由球参数解析 `√(R²−(R−h/2)²)`，半高带内取点）得直径→对 (x,y,h) 拟合最佳面得共面性偏差→NG 位（bit0 高度越界/bit1 直径越界/bit2 截面校验失败/bit3 位置度越界或未匹配名义点）→可选名义网格位置度（pitch>0 启用，nominal=origin+i·pitch，平移-only 不含旋转）。entries 按 apex(x,y) 升序（帧间稳定对应）。z-bin 哈希装箱避免 O(n²)（480K 点/2000 bump 量级无压力）。 |

**量测层已知局限**：DomeFit 基面为平面模型（晶圆弓形 30mm 尺度 <2µm 影响，够用）；CloudDiff 纯梯度/平面形貌对 XY 平移不可观测（含 z 常差对比需台阶/凸台锚定）；RegionPlane 跨台阶 ROI 折中拟合无唯一解。

## 9. ComUI 集成层 —— 统一 C ABI 与 83 个节点

### 9.1 统一 C ABI v1（`comui_native_abi.h`）

**调用模型**：每个算法节点对应 DLL 导出的一个 C 函数 `int32_t f(const AlgoCInput* in, AlgoCOutput* out)`，宿主按 `node.json` 的 params/连线声明组装输入调用。输出缓冲一律节点 `malloc` 分配，宿主用同 DLL 导出的 `void algo_free(void* p)` 释放（free 配对）。

**参数单元 `AlgoCParam`**（宿主 marshal **不带参数名**，适配层按 `node.json` params 声明顺序 + kind 取值，同 kind 多个以出现次序区分——`FindParam` 先例）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `kind` | int32_t | 0=double、1=int32、2=text(UTF-8)、3=bool(i≠0) |
| `d` | double | kind=0 有效 |
| `i` | int32_t | kind=1 有效 |
| `s` | const char* | kind=2 有效（UTF-8，宿主侧内存，节点只读） |

**输入/输出结构**：

| 结构 | 字段 | 说明 |
|------|------|------|
| `AlgoCImage` | `width, height, bgra` | 输入图像，BGRA 紧排（行步长 width×4），内存归宿主节点只读 |
| `AlgoCCloud` | `count, xyz, rgb` | 输入点云，xyz 交错 `[x,y,z,...]`，rgb 可 NULL |
| `AlgoCInput` | `paramCount/params, imageCount/images, cloudCount/clouds` | 三类输入，未连线的个数 0、数组 NULL |
| `AlgoCImageOut` | `width, height, bgra` | 输出图像（malloc，宿主 algo_free） |
| `AlgoCCloudOut` | `count, xyz, rgb` | 输出点云（malloc，同上） |
| `AlgoCOutput` | `imageCount/images, cloudCount/clouds, error` | error = 失败或结果消息（UTF-8 静态存储，宿主只读不释放） |

**返回码**：0 成功；1 输入缺失；2 输入无效/算子失败；3 参数不支持或内存不足；4 量测业务失败（拟合失败/无有效结果）。

**关键限制（ABI v1）**：`AlgoCOutput` **无 number/text 输出端口**——所有数值结果（圆心、配准 fitness、缺陷率、gray 统计等）两类呈现：① 画在输出图上（标注）；② 并入 `error` 字段以消息返回（rc=0 时也可非空，manual_regist 先例）。宿主 `NativeAlgo.cs` 目前仅 rc≠0 时读 error，**成功消息不显示**——真机确认项见 `docs/HOST_VERIFY.md`。

**结果呈现约定**：node.json outputs 一般有 image/cloud 端口；数值测量类结果并入消息：rc=0 表示流程成功。点云类测量以 z 维承载量测值（每 bump/孔/剖面一点，宿主伪彩即可视化）。

### 9.5 节点接入须知

- **放置**：`*.node.json` 与引用的 DLL 同放 `comdll/algo/<名称>/`；`assembly` 为相对 JSON 目录的路径；宿主启动与 F5 重载时递归扫描 `comdll/algo/**/*.node.json` 自动注册，**无需注册代码**；节点 id 冲突被静默忽略。
- **method** 必须与 DLL 导出函数逐字一致；参数与端口声明以 node.json 为准（宿主 marshal 不带参数名，**声明顺序即提取顺序**）。
- **热更新**：DLL 由 `Assembly.LoadFrom` 载入默认上下文，运行期文件被占用（覆盖失败）且不随 F5 卸载——改 DLL 先退出宿主再覆盖重启；仅改 node.json 可 F5 生效。
- **红线**：算子 DLL 禁止引用/创建任何 UI 控件；无 Initialize/Shutdown 生命周期（每次执行新建实例）；纯计算。详见 `docs/THIRD_PARTY_OPS.md` §9。

### 11.3 典型完整链路示例

**2D 缺陷检出**：`read` → `to_gray` → `blur`(中值) → `threshold`(OTSU) → `connected_components`(面积过滤) → 输出图绿框 + 消息计数。

**Mark 点对位**：`read`(搜索图) + `read`(模板) → `match_template_ex`(多尺度多角度) → 输出中心十字 + 消息 score/中心/尺度/角度。

**3D 凸台高度量测**：`read_sick` → `voxel_downsample` → `dome_fit` → 输出 bump 高度点云（z=高度）+ 消息统计。

**3D 金标准复检**：`read_sick`(基准) + `read_sick`(被测) → `cloud_diff`(align_search>0 粗对齐) → 输出差值点云 + 消息超差占比。

**业务 bump NG**：`read_sick`×2 → `business.bump_ng_check` → 输出 NG 差异点云 + 消息配对/NG 统计。
