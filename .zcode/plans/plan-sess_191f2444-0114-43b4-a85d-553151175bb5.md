## Context

`src/Image2DAlg` 目前只有 5 个 C 导出（版本/Init/Cleanup/FreeImage/ReadImage），通用处理能力只存在于 ComUI 适配层的 gamma 内联实现；`Image2DAlg_Calib.*` 是本模块下的标定接口类（用户进行中，本次不改）。本次把该模块补成真正的"通用 2D"库：**通用图像处理 + 测量/缺陷检测**，交付 **C ABI + C++ 实现 + 测试**，本期不出 node.json。

**定位**：Image2DAlg 是 `ShapelyAlg::ImageProcessor` 的**上层**，图像算子一律复用 ImageProcessor，不重复造轮子；链接 `ShapelyAlg`（PRIVATE），Image2DAlg 只做"业务参数语义 + C ABI 封装 + 结果结构组装"。

### 容器与通道语义
- `Image2DAlg_Image` 沿用 OpenCV 习惯：`channels` 为 **1/3/4**，`data` 紧排、行步长 `width*channels`，**不强制 4 通道**。
- 新增算子保持输入真实通道数（1→1、3→3、4→4，alpha 随通道一起参与 OpenCV 运算）。
- 天然单通道算子（ToGray/Threshold/Canny/equalizeHist）输出 **1 通道**，彩色输入内部先 `cvtColor` 转灰度。
- `ReadImage` 保持现状输出 BGRA（既有宿主契约，不改）。

### 代码风格（按反馈：不过度防呆）
- 只在 C ABI 边界做**最小必要校验**：空指针、空图、通道数、mode 范围；其余参数按 OpenCV 语义直接使用或一次钳制（如 gamma≥0.05、ksize 补奇），不写多层重复校验、不逐字段防御。
- 整函数级 `try/catch` 统一转 -99，异常不出 DLL；内部辅助函数不再各自 try/catch。
- 空测量结果视为正常（rc=0、count=0），不报错。

### 错误码
-1 空指针/空图、-3 通道/模式/参数不支持、-4 内存不足、-99 OpenCV 异常。其余不设专门错误码。

## 实施内容

### 1. CMake（`src/Image2DAlg/CMakeLists.txt`）
`target_link_libraries(${PROJECT_NAME} PRIVATE ShapelyAlg)`（其 PUBLIC include 已导出模块根与 src/，可直接 `#include "ImageProcessor.h"`）。

### 2. 公共 C ABI（`src/Image2DAlg/include/Image2DAlg_api.h`）
新增 13 个算子 + 结果结构与释放函数。

**通用处理（image→image）**
| 函数 | 输出通道 | 底层 |
|---|---|---|
| `Image2DAlg_ToGray` | 1 | `cvtColor` |
| `Image2DAlg_Gamma` | 同输入 | `lut`（公式同现 ComUI gamma，clamp ≥0.05） |
| `Image2DAlg_Threshold` | 1 | `threshold` / `adaptiveThreshold`（mode 0 二值/1 反二值/2 OTSU/3 自适应均值/4 自适应高斯） |
| `Image2DAlg_Blur` | 同输入 | `gaussianBlur`/`medianBlur`/`bilateralFilter`（4 通道双边拆 BGR 并保留 alpha） |
| `Image2DAlg_Morphology` | 同输入 | `makeKernel` + `erode/dilate/morphologyEx`（op 0~6；shape 矩形/十字/椭圆） |
| `Image2DAlg_Canny` | 1 | `canny` |
| `Image2DAlg_Resize` | 同输入 | `resize` |
| `Image2DAlg_Crop` | 同输入 | Mat ROI + clone（越界钳制到图内） |
| `Image2DAlg_Rotate` | 同输入 | `getRotationMatrix2D` + `warpAffine`，输出同尺寸 |
| `Image2DAlg_Enhance` | 1 或同输入 | `equalizeHist` / `clahe`（彩色走 Lab 亮度通道，4 通道保留 alpha） |

**测量/缺陷（image→结果结构）**
| 函数 | 底层 |
|---|---|
| `Image2DAlg_ConnectedComponents` | `connectedComponentsWithStats` + 面积区间过滤，返回 `Image2DAlg_Blob{label,area,left,top,width,height,cx,cy}` |
| `Image2DAlg_AnalyzeContours` | `findContours` + `contourArea`/`arcLength`/bbox/`getMinAreaRect`/`minEnclosingCircle`/`moments`，返回 `Image2DAlg_ContourInfo` |
| `Image2DAlg_MatchTemplate` | `matchTemplate` + `findBestMatch`，返回 score 与最佳左上角坐标 |

配套 `Image2DAlg_FreeBlobs` / `Image2DAlg_FreeContours`。版本 1.0.0 → 1.1.0。

### 3. 实现（新建 `src/Image2DAlg/Image2DAlg_Ops.cpp`）
- 静态辅助：`WrapInput`（零拷贝 Mat 视图）、`Gray`、`AllocOut`（按通道 malloc + memcpy）、`Binarize`、`MakeLut`。
- 每个导出函数：参数校验 → try/catch → 调 ImageProcessor → 组装输出。
- ImageProcessor 未封装的取值/组合直接用 OpenCV（ROI、`getRotationMatrix2D`、`arcLength`、`moments`、`split/merge`）。
- 输出数据一律 malloc，与三个 Free 配对。

### 4. 去重（`integration/comui/Image2DAlg_comui.cpp`）
`Image2DAlg_ComuiGamma` 改为调用 `Image2DAlg_Gamma`（BGRA 进、BGRA 出），节点行为不变；不改 node.json。

### 5. 测试（`src/Image2DAlg/Image2DAlg_test.cpp`，只增不改）
现有 21 check 全保留，新增约 40-50 个，合成图自包含、临时文件自清理：
- 灰度（3→1、4→1）、Gamma 已知值、固定阈值/OTSU/自适应（channels==1）；
- 模糊（常量图不变、中值去噪、通道保持）、形态学（膨胀面积 9、腐蚀归零）、Canny（边缘非空、内部 0）；
- Resize/Crop/Rotate 尺寸/通道/采样像素；
- Enhance 动态范围扩大；
- 连通域（两方块→2 blob、面积/bbox、min_area 过滤）；
- 轮廓（方块 area/perimeter/bbox/circularity/minRect 容差）；
- 模板匹配已知位置（位置精确、score≈1）；
- 关键错误路径：空指针、2 通道、非法 mode、Free NULL 安全（不做穷举）。
