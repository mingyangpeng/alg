# 八叉树/体素空间检索 C API 开发（1.8.0，批次 B 3.4）

## Context

用户要求核实 3D 空间领域检索（体素/八叉树/KdTree）接口是否已开发，缺则补。核查结论：
- **KdTree**：✅ 已有 `Point3DAlg_KnnSearch`/`RadiusSearch`/`FreeSearchResult`（1.2.0，PCL KdTreeFLANN）+ 2 节点，不重复开发
- **体素**：仅有体素**降采样**（FilterCloud method 0/10），无体素**检索**
- **八叉树**：`CloudProcessor::treeOctreeVoxelSearch`/`treeOctreeChangeDetection` 底层已实现且带守卫，但未过 C API。待开发接口.md §3.4 标注"索引数组 → 需 ABI v2 blob"已过时——§9.9 搜索组的 `int**/float**` malloc 输出通道（KnnSearch 在用）就是索引数组通道，现在即可落地

方案：**新增 3 导出 + 3 节点**，版本 1.7.0 → 1.8.0（"新增 3 导出"）。八叉树 KNN/半径与 KdTree 结果完全相同，按仓库"不重复封装"原则跳过。命名不带 `Tree` 前缀（对齐已发布的 §9.9 风格 `KnnSearch`/`RadiusSearch`；待开发清单里的 `TreeOctree*` 是旧建议，剔除表登记时注明改名）。

## 新增 C API（复用 §9.9 输出契约与 FreeSearchResult）

```c
/* 体素检索：查询点所在体素（边长 resolution）内全部点 */
int Point3DAlg_OctreeVoxelSearch(const Point3DAlg_PointCloud* in,
    const double query[3], double resolution,
    int** out_indices, float** out_dists, int* out_count);

/* 八叉树盒检索：轴对齐盒内全部点（kdtree 无对应查询） */
int Point3DAlg_OctreeBoxSearch(const Point3DAlg_PointCloud* in,
    const double box_min[3], const double box_max[3],
    int** out_indices, float** out_dists, int* out_count);

/* 八叉树变化检测：in_cmp 相对 in_base 新占体素的点索引 */
int Point3DAlg_OctreeChangeDetection(const Point3DAlg_PointCloud* in_base,
    const Point3DAlg_PointCloud* in_cmp, double min_resolution,
    int** out_indices, float** out_dists, int* out_count);
```

口径（写入 api.h §9.9 注释块扩展）：
- 输出通道与 KnnSearch/RadiusSearch 完全一致（库 malloc、两者可传 NULL、count 恒回填、`FreeSearchResult` 释放）；0 命中 = 0 成功；错误码 0/-1/-3/-4/-99，-2 不使用
- dists 语义：VoxelSearch = 到查询点欧氏距离升序；BoxSearch = 到盒中心欧氏距离升序；ChangeDetection = 全 0 占位（无距离语义），索引保持体素遍历序
- 参数校验：resolution/min_resolution <= 0 → -3；box 逐维 min >= max → -3；双输入 NULL → -1；**in_base 空云合法**（in_cmp 全部点为新增）
